Privacy policy

Last updated: October 26, 2026

This policy covers the hosted sysketch server at sysketch.vercel.app, which AI chat apps such as Claude and ChatGPT use to draw diagrams. sysketch is an open-source project; questions go to the address at the end.

What we receive

When you ask your AI app for a diagram, the app sends sysketch a short text description of the diagram (its parts, arrows and labels). We use it only to draw that diagram. There are no accounts, and we don't ask for or receive your name, email or chat history.

What we keep

  • No diagram storage. Descriptions are not saved to any database. Each diagram link contains its own description in compressed form, so the link is the only copy, and anyone you share a link with can see that diagram.
  • Hosting logs. Our hosting provider, Vercel, keeps standard request logs (time, IP address, and the requested URL, which for diagram links includes the compressed description) for operations and security, for the period its plan allows. We don't copy these logs elsewhere or use them for anything else.
  • Image caching. Vercel's network caches rendered diagram images so repeat views load quickly.
  • Anonymous usage counts. To see how much sysketch is used, we count per day how many diagrams are drawn or fail, their type (such as architecture or sequence), which AI app sent them (the first word of its user agent, like claude-user), and which apps connect. We also estimate how many different users there are each day: a one-way hash of your AI app's anonymous user ID if it sends one, otherwise of the IP address and user agent, mixed with a random value that changes daily and is deleted after two days. Only an approximate total is kept from these hashes, not the hashes themselves. We never store diagram descriptions, IP addresses or user IDs, and the counts are deleted after 400 days.
  • Rate limiting. To prevent abuse, the server counts requests per IP address in memory for one minute. These counts are not stored.

We don't use cookies, advertising or tracking, and we don't sell or share data. The usage counts above are our only analytics.

Third parties

Vercel hosts the server (Vercel's privacy policy). Upstash stores the anonymous usage counts (Upstash's privacy policy). Your AI app sends requests to sysketch on your behalf, and its own privacy policy covers your conversation.

Your choices

Don't put secrets or personal data in diagrams. To draw diagrams without sending anything to a server, use the local version of sysketch, which runs on your own computer.

Children

The service isn't directed at children under 13.

Changes and contact

We'll update this page and its date if anything changes. Questions or requests: open an issue on GitHub.
