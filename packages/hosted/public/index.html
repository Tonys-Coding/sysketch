Describe your system. Get the diagram.

Add sysketch to your AI assistant and ask for a system design diagram. The assistant writes a few lines describing your system, and sysketch draws a clean, hand-sketched diagram you can open, download or share.

Server URL

/mcp

Claude (web, desktop and mobile)

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it sysketch, paste the server URL and click Add. No sign-in is needed.
  3. In a chat, ask: “Use sysketch to draw a ride-sharing system.”

ChatGPT

  1. Open Settings → Apps & Connectors → Advanced and turn on Developer mode.
  2. Choose Create, name it sysketch, paste the server URL and pick No authentication.
  3. In a new chat, turn on sysketch from the + menu and ask for a diagram.

Other assistants

Any app that supports remote MCP servers over Streamable HTTP can use the same URL. Coding assistants like Claude Code and Cursor can also run sysketch on your computer, which saves diagrams straight into your project and supports official logos: see the setup guide.

Privacy

Nothing is stored. Each diagram link contains its own description, so anyone you share a link with can see that diagram. Don’t put secrets in diagrams.
