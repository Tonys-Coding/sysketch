Describe your system. Get the diagram.

Your AI writes a few lines describing your system. sysketch draws a clean, hand-sketched architecture, sequence or cloud diagram you can drop into docs, slides or a pull request.

Add a custom connector in Claude, ChatGPT or Perplexity with this URL. No account needed.

https://sysketch.vercel.app/mcp

Run this once in your terminal. Diagrams are saved in your project.

claude mcp add sysketch -- npx -y sysketch-mcp

Add this to your assistant's MCP settings and restart it. Needs Node.js 20 or newer.

{ "sysketch": { "command": "npx", "args": ["-y", "sysketch-mcp"] } }

The whole language fits on an index card

Arrows, optional parts and groups. Common names like redis, kafka or stripe pick the right icon by themselves, and mistakes come back as fixes: unknown node “databse”. Did you mean: database?

Works where you already ask

AI chats

Claude, ChatGPT and Perplexity, through one connector URL. In Claude and ChatGPT the diagram opens right in the chat, with zoom and downloads.

Coding assistants

Claude Code, Cursor, VS Code, Windsurf, Gemini CLI and any app that runs MCP servers. Diagrams are saved next to your code, with their description, so changes are a one-line edit.

Command line and code

npx sysketch render diagram.yaml writes an SVG or PNG. In Node, render(spec) returns the SVG.

Set it up in a minute

  • Claude (web, desktop and mobile)

    Settings → Connectors → Add custom connector. Paste https://sysketch.vercel.app/mcp.

  • ChatGPT

    Turn on Developer mode under Settings → Apps & Connectors → Advanced, then create a connector with the same URL and no authentication.

  • Claude Code

    Run claude mcp add sysketch -- npx -y sysketch-mcp once in your terminal.
